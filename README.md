# Tactivo — demo build

A shareable build of the Tactivo coaching app. **[Open the demo](https://carlbres0.github.io/tactivo-demo/)**

Sign in with the sample coach account — the sign-in screen has a "Try the demo"
button that fills it in for you:

| | |
| --- | --- |
| Email | `coach@tactivo.app` |
| Password | `tactivo123` |

Everything runs in your own browser. There is no server, no account, and
nothing you do here reaches anyone else — clearing site data resets the demo.

This repository holds only the compiled web build. The source lives elsewhere.
